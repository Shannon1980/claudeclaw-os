|----------|-------------|

| .md body at fire time → runAgent | the re-read prompt body is executed as the aos agent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-08 | Tampering / integrity | double-fire across main + aos processes | mitigate | aos branch fires only when claimDueTask returns changes===1; agent-scoped getDueTasks already prevents main from reading aos rows; the atomic claim covers the startup/shutdown race window. Proven by the concurrent-claim test (SCH-04). |
| T-07-09 | Tampering / Elevation | prompt body re-read and executed at fire time | accept | job_path is constrained to the synced aos cron dir; the body is the user's own workspace source of truth (same trust as the retired engine). Read failure falls back to the stored projection + logs rather than executing arbitrary external content. |
| T-07-10 | Denial of Service | a job hanging past its window | mitigate | per-job parsed timeout (fallback TASK_TIMEOUT_MS) aborts via AbortController; retry is bounded by the row's retry count so a failing job cannot loop unbounded. |
