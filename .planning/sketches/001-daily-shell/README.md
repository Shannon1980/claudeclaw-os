# Sketch 001: Daily Shell

## Design Question
What layout should the operator live in? Same graphite look, three quieter information architectures versus the current catalog.

## How to View
open .planning/sketches/001-daily-shell/index.html

## Variants
- **Now** — Current Home + 12-item sidebar. Baseline, not a proposal.
- **A: Today rail** — Six destinations. Needs you first. One work list. Week strip. One composer.
- **B: Split** — Icon rail. Today on the left, Chat always open on the right. Talking is never a separate page.
- **C: Inbox** — No sidebar. Needs you is the whole page. Command bar to jump. Detail slides in when you pick a row.

## What to Look For
- How fast you can approve something
- Whether you know where to type
- How much chrome you ignore before the work
- Whether Chat belongs beside Today or behind a click
