<objective>
Fix the three packaging-correctness bugs that make a signed build fail before the user ever sees the dashboard, in the order they break the boot: (1) writable-state redirect — route .env/store/logs to app.getPath('userData') because process.resourcesPath/app is read-only under Gatekeeper; (2) migration gate — run migrations through a NON-INTERACTIVE runner before forking the service so checkPendingMigrations()'s process.exit(1) can never silently kill it, and so the runner never blocks on a [y/N] prompt that has no TTY behind it; (3) native ABI — rebuild better-sqlite3 for Electron's Node ABI via prebuilt binaries (the dev-machine toolchain cannot source-compile) and PROVE the ABI match early.

These are prerequisites for the first real end-to-end launch test (plan 04). PKG-02 (boot the service internally and open the dashboard) cannot be true until all three are fixed.

Purpose: make the packaged service actually boot and bind its dashboard on a clean machine.
Output: data-dir-aware config, a non-interactive migration runner + a migration-before-fork boot path, and a build that ships an ABI-correct native module.
</objective>
