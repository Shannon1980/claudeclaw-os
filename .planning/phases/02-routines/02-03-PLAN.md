## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser client → /api/routines* (dashboard HTTP) | Untrusted request body (description, cron, steps, autonomy) crosses into the server behind the DASHBOARD_TOKEN bearer gate |
| operator description → runAgent SDK subprocess | Free-text description is sent to the LLM for structured-output assembly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Spoofing | Unauthenticated access to /api/routines* | mitigate | All routes mount behind the existing DASHBOARD_TOKEN bearer gate (dashboard.ts auth); no new auth surface (ASVS V2/V3 reuse) |
| T-02-08 | Tampering / DoS | Malformed draft JSON from the model → unhandled 500 / injected control chars | mitigate | parseJsonLoose + shape validation; on parse failure return a friendly { error }, never persist unvalidated draft (Pitfall 4) |
| T-02-09 | Tampering | Invalid cron / unknown agent_id / bad autonomy or on_error enum persisted | mitigate | computeNextRun validates cron (400 on throw); agent_id validated against listAgentIds (fallback main); autonomy ∈ {unattended,queue_approval}, on_error ∈ {continue,stop}; reject empty step lists; cap action length (V5) |
| T-02-10 | DoS | Run-now flooding / overlapping runs | mitigate | claimDueTask 409 + the shared runningTaskIds guard prevents concurrent runs of one routine |
| T-02-11 | Information Disclosure / Integrity | Draft endpoint silently persisting before confirm (D-05 violation) | mitigate | /api/routines/draft returns JSON only; only POST /api/routines writes; contract test asserts unchanged row count |
| T-02-04b | Access Control | Stored autonomy mistaken for an enforced control | accept (this phase) | autonomy is persisted + passed forward only; enforcement is Phase 3 (D-08). Routes/UI must not present it as a security guarantee |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages (RESEARCH Package Legitimacy Gate: N/A) |
