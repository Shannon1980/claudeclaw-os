<objective>
Close the delegation-path file-marker gap so a delegated agent (reached via `@id:`) can deliver a real file as a chat attachment, and regression-guard it with two unit tests (space-in-path parsing + delegation extraction). This is the load-bearing code work of Phase 2 and MUST land before the live SK-03 verification in plan 02.

Per locked decision D-1(a): mirror `src/mission-files.ts` — the gap is that `src/message-core.ts` posts the delegated `result.text` raw through `sendFormatted` without running `extractFileMarkers`, so any `[SEND_PHOTO:]`/`[SEND_FILE:]` the agent emits leaks into chat as literal text and the file is never uploaded. Fixing the delegation branch (not just routing one agent through a channel) is the consolidation win: it fixes file delivery for the whole fleet of delegated agents.

Purpose: Without this, SK-03 cannot be proven over the `@aos:` delegation route — the only route `aos` has today.
Output: Patched delegation branch in `src/message-core.ts`; new unit cases in `src/format.test.ts` and `src/message-core.test.ts`.
</objective>
