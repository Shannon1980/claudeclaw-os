<objective>
Build the ClaudeClaw-side replacement for memsearch terminal recall (D-01): a positional-arg recall CLI plus a thin `recallForWorkspace` wrapper that shares the bot's exact embed+search path against the single SQLite source-of-record store. This is the vertical slice that makes terminal semantic recall possible BEFORE anything memsearch-related is disabled (D-06 sequencing).

Per D-01: the CLI mirrors capture-cli.ts's run-as-main idiom and schedule-cli.ts's arg parsing, queries ClaudeClaw SQLite embeddings via the new wrapper scoped to workspaceMemoryKey('aos')='ws:aos' and strict agentId='aos', and is reached through the `~/.claudeclaw-app` symlink. Per D-04: this plan does NOT write to, migrate, or delete `.memsearch/memory/` (the recall path reads only the `memories` table; the archive stays frozen).

Purpose: Deliver MEM-05's surviving recall surface so the agentic-os Tier-1 instructions (Plan 02) have a real command to point at, and the index can be disabled (Plan 02/03) without losing terminal recall.

Output: `src/recall-cli.ts`, `recallForWorkspace` export in `src/memory.ts`, `src/recall-cli.test.ts`, and a built `dist/recall-cli.js` reachable via the `~/.claudeclaw-app` symlink.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| terminal argv to recall-cli | Untrusted query string (and optional --top-k) crosses into the CLI |
| recall-cli to SQLite store | The CLI reads the shared memories table; per-agent scope must hold |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | recall-cli / recallForWorkspace scope (PRIMARY threat per phase intent) | mitigate | Fix chatId to workspaceMemoryKey('aos')='ws:aos' and pass strict agentId='aos' as searchMemories arg 4; the Wave 0 invariant test asserts both args so cross-agent/cross-chat memories cannot leak |
| T-06-02 | Spoofing | agent attribution via argv | mitigate | Hardcode RECALL_AGENT_ID='aos' server-side; never read an agent id from argv (capture-cli precedent) |
| T-06-03 | Tampering | FTS5 query injection via crafted query | mitigate | Route only through searchMemories, which strips double-quotes and wraps as an FTS5 phrase (db.ts:938); the CLI never builds raw SQL |
| T-06-04 | Denial of Service | unbounded query / top-k | mitigate | Cap the query at MAX_QUERY_CHARS=4000 (capture-cli precedent); bound --top-k with default 10 |
| T-06-05 | Information Disclosure | reading encrypted messaging tables | accept | recall reads only plaintext memories.summary via searchMemories; never touches wa_*/slack_messages (MEM-06 path preserved); no new code reads ciphertext |
