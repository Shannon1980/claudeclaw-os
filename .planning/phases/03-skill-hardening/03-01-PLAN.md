<objective>
Harden the `aos` workspace agent so its file-producing and self-improvement skills work over chat. Two failure modes from Phase 2 are closed with a single operational instruction overlay: (1) skills that copy output to ~/Downloads silently succeed but the chat user never sees the file (SK-04 — fix is to ALSO emit a `[SEND_FILE:]` marker, reusing Phase 2's proven delivery path), and (2) skill self-improvement writes to `context/learnings.md` are gated behind an interactive feedback question or session-end that never fires in a one-shot delegated bot turn (SK-05 — fix is an inline write during the turn).

Purpose: Make output visible over chat and keep self-improvement flowing, without forking upstream agentic-os skills, without touching the env scrub or deny list, and without wiring a ClaudeClaw-side hook. The workspace stays portable for terminal use.

Output: A minimal, operational `~/.claudeclaw/agents/aos/CLAUDE.md` overlay (outside the repo, like the Phase 1 agent.yaml), plus live transcripts proving SK-04 and SK-05 over chat. The overlay content is captured verbatim in the SUMMARY for reproducibility.
</objective>
